## ADDED Requirements

### Requirement: Execute Judge Agent post-scan
The system SHALL extend the main scanning orchestrator in `main.py` to forward all pre-screened candidates generated by `scan_all(mode)` to the Judge Agent. The system SHALL then display the curated top 10 candidates with their qualitative verdicts on the console and persist the full results structure to disk.

#### Scenario: Orchestrate scanning and qualitative judging
- **WHEN** the main scanning pipeline is triggered via the command line interface
- **THEN** the system SHALL run the parallel scan batch, send the resulting candidates list to `run_judge()`, output a beautifully formatted report to standard output, and save the curated top 10 to `data/top10.json`
